# Three Awesome Things About Writing in Markdown

Real words said by me today:
> I had a lot of fun learning Markdown.

On the first day on this topic, we learned the very basics, like how to start a paragraph, make headings, italicize text, and bold text. On the second day, we learned how to make unordered and numbered lists, insert quotes, and document code.

## Number 1: I can write Markdown anywhere, all the time

I don’t need a special application on my computer to “run” Markdown like I would need for Python or Java. Some places I could write Markdown include
Google Docs supports Markdown, which means I can write it offline if I wanted. Furthermore, GitHub is like any other website accessible on the web, so I can easily find those projects as long as I have an electronic with web access. I could even write it in my Apple Notes app on my phone if I really wanted to to paste into Google Docs or GitHub later. 

## Number 2: Markdown is forgiving of people with long-term memory loss (like me)

After learning Python and Java, I find it hard to separate the rules for each one. They start to jumble together, and I’m left with not being confident in either coding language because I don’t know which rules apply to which language. 

Markdown is a lot simpler to remember. For one, Markdown has a bunch of ways to do the same thing:
1. **Headings**: hashtags *or* equal signs/dashes
2. **Italic text**: one asterisk *or* one underscore around text
3. **Bold text**: two asterisks *or* two underscores around text
4. **Unordered list**: one asterisk and a space *or* one hyphen and a space

This is nice because I get to choose whichever one is easier for me to use, and it also means that as long as I remember one way to do something, I’m good to go. 


## Number 3: Learning Markdown is transferable skill

By edging on the side of extra safe when using lots of blank lines, I’m preparing myself for platforms that may use a stricter form of Markdown. That opens up a lot of platforms that have Markdown for me to write in:
- GitHub
- GitLab
- Google Docs
- And many more…

Hopefully having this basic understanding of Markdown gives me a head start to learning how to write on any platform, which in turn makes me a competitive candidate when applying for jobs!
